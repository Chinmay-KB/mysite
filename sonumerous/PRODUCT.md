# Sonumerous

Platform: web. A private, mobile-first image studio at sonumerous.chinmaykabi.com.
Create images using OpenRouter models, reusable uploads, and editable themes. Refine any past result with text and optional region selection. Every uploaded or generated image is permanently reusable; the original is preserved with branching history. Store fixes and explicitly remembered preferences. Email-code login through Cloudflare Access. The owner bears all operating costs; no pricing, credit, billing, or payment UI.

Stack: React, TypeScript, Vite; Cloudflare Workers, D1, private R2, Images, Workflows.
Initial theme: an editable 1980s portrait template. Avoid making the entire product theme-specific.
No sample generations may masquerade as the user's work. Empty states should be useful and composed.
Visual commitment: user selected Clean gallery—neutral white, restrained controls, photography-gallery presentation. Operate for Create/Refine; Experience for Library.
